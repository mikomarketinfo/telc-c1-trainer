# TELC C1 Engine

Open-source platform for preparing for the TELC C1 Allgemein exam.

## Features

- Modular architecture
- JSON-based tests
- Adaptive learning
- Detailed explanations
- Statistics
- AI-ready architecture
- GitHub Pages compatible
