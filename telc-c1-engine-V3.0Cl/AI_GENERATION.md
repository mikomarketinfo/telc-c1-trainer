# AI Generation — Процесс генерации тестов

Версия: 2.0 (заменяет версию 1.0, где генерация описывалась как текст "с нуля",
без привязки к реальным статьям)

## Принцип

TELC C1 Engine — статический сайт без бэкенда. Поэтому генерация новых тестов —
**не функция самого сайта**, а отдельный оффлайн-процесс, результат которого
(готовый JSON) коммитится в `data/`. Полный процесс, обязательные copyright-правила
и чек-лист качества описаны в файле `AI_GENERATION_PIPELINE.md`.

## Кратко: откуда берутся тесты

1. Источники: ZDF, Tagesschau, DW, Deutschlandfunk, Spektrum, Zeit Wissen (плюс
   вторичные источники для фактуры/статистики — ifo, IW Köln, Destatis, DIHK и т.п.).
2. Разрешено использовать статьи и данные последних 1-2 лет (не только текущего года).
3. Текст пишется заново на основе фактов из нескольких источников — **никогда**
   не копируется дословно.
4. Каждый сгенерированный тест содержит поле `generator` (см. `DATA_FORMATS.md`):
   ```json
   "generator": {
       "source": "краткое описание тем/источников, не дословный текст",
       "validated": false,
       "validatorVersion": "1.0"
   }
   ```
5. `validated` становится `true` только после прохождения чек-листа качества
   (структура, однозначность правильного ответа, объём текста, отсутствие
   дословных совпадений с источником, соответствие уровню C1).
